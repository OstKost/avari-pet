Белые волосы, заострённые уши, спокойный характер, тёмный сине-зелёный плащ, сдержанное старое золото. Код выполняется как магия: символы скобок сплетаются между ладонями.

Палитра: #06141B, #0A1D26, #102833, #F2F0E8, #A8B4B7, #D9B96E, #6EA8C4.

Предлагаемые действия:
- idle: дыхание, моргание, лёгкое движение волос.
- running-right: лёгкие шаги вправо, движение плаща.
- running-left: лёгкие шаги влево, движение плаща.
- waving: мягкое приветствие рукой.
- jumping: короткий радостный прыжок.
- failed: заклинание сжимается в ладонях; озадаченный взгляд.
- waiting: вопросительный взгляд на пользователя и открытая ладонь.
- running: сосредоточенно сплетает символы кода в заклинание.
- review: внимательно рассматривает созданную печать кода.
